# Page Post

লেখা + ছবি শিডিউল পোস্টের অ্যাপ (Facebook Page)।
GitHub-এ পুশ করলে Actions নিজেই APK বানায়: Actions -> Build APK -> Artifacts -> PageNotes-APK।

## v2.0 নতুন
- টোকেন (ও AI Key) ফোনে সেভ থাকে, প্রতিবার দিতে হয় না
- ক্যাপশন + ছবি + সময় দিয়ে পোস্ট সেভ (ড্রাফট) → পরে এখনই পোস্ট বা Facebook-এ শিডিউল

- অ্যাপের ভেতরেই Facebook লগইন (App ID দিয়ে) ও Facebook ব্রাউজ (🌐)
